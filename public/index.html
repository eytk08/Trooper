What Trooper automates

Every step that used to need a staff member, a phone call, or a paper list.

Live slot generation

Open times are built from each doctor's schedule in the database. Change a schedule and the chatbot shows the new times right away.

No double booking

Each booking is checked inside a database transaction, so ten people tapping the last slot at once still get only the places that exist.

Automatic doctor matching

First time patients do not have to compare doctors. Trooper finds the earliest open time across the whole clinic and offers it.

Instant confirmation and reminders

A reference code and a text message are created the moment a booking is made. A background job sends a reminder before the visit and retries failed messages.

Self service changes

Patients check or cancel with their reference code and mobile number. The slot is released and queued reminders are dropped automatically.

Live staff dashboard

Staff see today's appointments, doctor workload, and the message log in one page, with no manual updating. Open the dashboard.

About Trooper

Trooper is a chatbot and scheduling system that takes over the routine work of booking hospital appointments. It started as MedSched, a proposed scheduling system for the Veterans Memorial Medical Center, and was rebuilt around a MySQL database so that availability, booking, reminders and cancellations run without staff involvement.

Built with Bootstrap 5, Node.js, Express and MySQL. The hospital details in this demo are public information used as an example.
